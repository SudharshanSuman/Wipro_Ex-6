# Wipro Java Ex-6: Student Examination Result Processing System

## Aim
To develop a Student Examination Result Processing System using HTML forms and Java Servlets to handle form data, perform mark and eligibility calculations, determine grades and pass/fail status, and dynamically display the examination result.

## Description
This exercise involves developing a web application using:
- **HTML Forms** - For student data input
- **Java Servlets** - For server-side processing

### Program Files:
- **ResultServlet.java** - Servlet for processing examination results
- **Index.html** - HTML form for student data entry

### Features:
- Form data handling
- Mark and average calculations
- Grade assignment
- Attendance eligibility checking
- Dynamic generation of examination result using HTML tables

## Result
The Student Examination Result Processing System was successfully developed using HTML and Java Servlet. The application was implemented and executed successfully in Eclipse with Apache Tomcat, demonstrating form data handling, mark and average calculations, grade assignment, attendance eligibility checking, and dynamic generation of the examination result using HTML tables.
